# Garbage Classification using Deep Learning

A Deep Learning-based system that classifies garbage images into different waste categories.

## How It Works

1. Upload a garbage image.
2. The image is preprocessed.
3. The trained Deep Learning model analyzes the image.
4. The model predicts the garbage category.
5. The prediction result and confidence are displayed.

## Technologies

* Python
* TensorFlow
* Deep Learning
* OpenCV
* Image Processing

## Dataset

The dataset used for this project was obtained from Kaggle.
